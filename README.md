## Proqramin iş prinsipi

Bağlı siyahı düyünlərdən ibarətdir. Hər düyün dəyəri (data) və növbəti düyünə istinadı (next) saxlayır. Siyahının birinci düyünü head dəyişənində saxlanılır, sonuncu düyünün next-i None olur. Əməliyyatlar LinkedList sinfinin funksiyaları ilə yerinə yetirilir: düyünlərin əvvələ və sona əlavə edilməsi, silinməsi, axtarılması və siyahının tərsinə çevrilməsi.
